IGNORE
Author: Command Master
Keywords: ignore
Type: Command

Syntax: chat <message> - displays an OOC message to all players viewing chats.
Syntax: chat - toggles viewing chats on/off.


The ignore command allows you to ignore all OOC channels from a player.

Due to disguise and various ways to change your name, there is no information give or
displayed for listed ignores.

See: help class ats.commands.communication.NewbieChatCommand, help oracle, help think, help
tellchat, help groupchat, help replay, help channels
