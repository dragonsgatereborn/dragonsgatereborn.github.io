In-Game Help Text

ORACLE
Author: Command Master
Keywords: oracle elder staff gm gamemaster guide assist
Type: Command

Syntax: oracle <message> - sends a help message to staff members. If there are no staff members on, this will send an email to Dayrinni.
    An email can only be sent every 30 seconds (game wide).
    In addition, all oracles are saved per server session so staff can see them upon logging into the game at a later date!


The oracle command allows a player to send a Helper and Staff wide help message. Any active


Helper and Staff will see this message and assist you.

If there are no staff online, a notification will be sent and the message logged for when a
staff member enters the game.

You may email Dayrinni(dayrinni@tempestseason.com) for assistance.

You may also try other help files which could provide assistance: channels, feedback,
discord, stuck.

See: help class ats.commands.communication.NewbieChatCommand, help feedback, help channels,
help discord, help stuck
