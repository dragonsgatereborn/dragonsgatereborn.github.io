In-Game Help Text

ORDER
Author: Command Master
Keywords: order
Type: Command

Syntax: order <player>|<longID>|all <command> - orders NPC(s) to do a command. To find longID, use call list
Syntax: order <player>|<longID>|all kill <target> - orders NPC(s) to attack the target. To find longID, use call list
Syntax: order <player>|all stop - cancels any current combat action.
This command is logged. Abuse is NOT tolerated! Pets do not save their inventory and any given items CAN BE LOST!


The order command allows control of pets and other followers.

To have your pets and followers attack a target, order them to kill <target>

For example, if a pet can speak, you could make it say something like so: order thug say
Hey there.

This command is logged. Abuse is NOT tolerated! Pets do not save their inventory and any
given items CAN BE LOST!

See: help call, help role play
