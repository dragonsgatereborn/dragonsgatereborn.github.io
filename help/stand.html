In-Game Help Text

STAND
Author: Command Master
Keywords: stand
Type: Command

Syntax: stand - stands up if you're not already standing.
Syntax: stand <item> - tries to stand on an item in the room
Syntax: stand off - to step off of the current item you're standing on


The stand command puts your character into an upright, default, position.

It is possible to stand on an item in the room, such as a chair, table or rune.

To step off of an item, type: stand off

See: help liedown, help sit, help sleep, help wake, help rest
