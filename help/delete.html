In-Game Help Text

DELETE
Author: Command Master
Keywords: delete
Type: Command

Syntax: delete now - begins deletion process.
Syntax: delete confirm - to confirm deletion after 'delete now' is typed.
Syntax: delete cancel - to cancel deletion.


The delete command allows you to remove the character from your account and game world.


This is a two step process and can be completed by typing the following commands:

delete now


delete confirm


In the event of a mistaken deletion, please contact Dayrinni@tempestseason.com for a
restoration request.
