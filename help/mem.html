MEM
Author: Command Master
Keywords: mem
Type: Command

Syntax: mem <alias> <corridor number> - assigns a shortcut name to a corridor.
Example: mem dart 1 - names corridor 1 as 'dart'.
Then use INVOKE DART to cast it. Use INFO RUNESPELLS to see your corridors.
