WEAR
Author: Command Master
Keywords: wear
Type: Command

Syntax: wear <item>|<slot> [wear slot] - wears an item on the default slot or the provided one. Slot is optional.
Syntax: wear <inventoryIndex> [wear slot] - wears an item at the inventory slot on the default slot or the provided one. Slot is optional. (Check inventory for index)
Note: If using the wear slot option, it must be fully typed out. For example wear ring right finger (NOT right fing)


The wear command allows you to wear or equip an item. If an item is already equipped, it'll
be replaced.

You may also specify what wear location to wear an item at if the item has mulitple slots.
For example, wearing a headdress as a HAT rather than a HEAD (armor).
