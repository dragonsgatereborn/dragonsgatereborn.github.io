In-Game Help Text

TARGET


Author: Command Master
Keywords: target diagnose
Type: Command

Syntax: target <target> - locks all non-AE hostile abilities and attacks onto the indicated target.


The target command allows a player to lock onto a target where all attacks and hostile
abilities(skills, spells, etc) will be directed to said target if they are present.

When a target is locked on a (Target) tag will appear by their name in the room.

NOTE: Whenever you use a hostile ability the game will automatically lock onto that target.

For healing targets, see help ally
