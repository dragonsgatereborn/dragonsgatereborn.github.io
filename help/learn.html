In-Game Help Text

LEARN
Author: Command Master


Keywords: learn
Type: Command

learn list - lists the abilities and specializations that can be learned at this location.
learn ability <slot> - learns the ability from the trainer for a fee.
learn spec <slot> - learns the specialization from the trainer for a fee.
learn fromItem|item <item name>|<slot> - scribes the knowledge from an item in your inventory, which may give new specializations or abilities.

See help learn for more information.

To train existing abilities, see the train command.


The learn command learns a new ability or specialization at the trainer.

Abilities can be learned at any level at the trainer.

Specializations can be learned starting at level 25 at the trainer.

(Mages learn from Scrolls and Blood Shamans from Totems found in the wild).
