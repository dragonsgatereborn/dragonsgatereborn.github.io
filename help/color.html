In-Game Help Text

COLOR
Author: Command Master
Keywords: color colorset ansi colors colours
Type: Command

Syntax: color set <type> <colorTag>|default - sets the given type to use the indicated color tag.
Syntax: color list - lists all current colors.

Syntax: color brief - toggles brief color on/off.
Syntax: color none - toggles no color on/off.
Syntax: color xterm - toggles xterm color(256 colors - need client support) on/off.
Syntax: color trueColor - toggles true color on/off and xterm on if off.


The color command can change many aspects of color in A Tempest Season.

The following color codes exist:
#c/#C: cyan/bright cyan
#r/#R: red/bright red
#g/#G: green/bright green
#b/#B: blue/bright blue
#p/#P: purple/bright purple
#y/#Y: yellow/bright yellow
#s/#S: gray/black
#w/#W: gray/white
#d: default color
#h: default highlight color
#x: terminates color and reverts to client's default


The game also supports xterm color (type: color xterm to turn on):
#e1 to #e255: a specific color, that matches the chart from the following website:
https://i.stack.imgur.com/KTSQa.png

The game also supports true color (type: color trueColor to turn on):
#t(6-digit hex code): a specific color that matches the hex code in rgb color space. Example: #t(e3cdb6)
#t[keyword]: a specific color that matches the keyword. Example: #t[cotton]
 Note: Keywords are added by Actinate and Dayrinni. Not all keywords will exist.
