In-Game Help Text

CONFIG
Author: Command Master
Keywords: config set
Type: Command

Syntax: config <config type> - toggles the config option on/off.
Example: config NO_COLOR - toggles the coloring of text on/off.

Syntax: config screenreader - sets your configuration setup to work better for screeneaders.
Syntax: config buffersize <lines> - sets the number of lines per Hit Enter text.
Syntax: config export [delimiter] - exports configs for use in another character (copy and paste). If 'delimiter' is used, output is on a single line.

Syntax: config list - views the current configuation setup.
Syntax: config types - views each config and their description.

Syntax: config messages <messageType> <mode> - sets mode (FULL, BRIEF, NONE) for a given message type(YOURS, OTHER).
Syntax: config messages list - views current modes for all messages.
Syntax: config batchedcombat - toggles batched combat message mode on/off.

To change colors, see color help


The config command allow you to control certain features and behavior in the game. For
example, this command can be used to turn the map on/off, chat color, and hints.

To configure color, see help color

Configs can be exported with config export for use on other characters.

See: help inspect, help inventory, help brief, help color, help channels
