REPLY
Author: Command Master
Keywords: reply
Type: Command

Syntax: reply <message> - sends a tell to the last person you messages or messaged you.


The replay command allows you to send a direct tell to the last person that sent you one.

The purpose of this command is to make it easier to have one-on-one conversations in
tells..

Note: If talking to more than 1 person at once in tells, it is suggested to avoid using the
reply command due to the high chance that a message will be sent to the wrong person. Use
the tell command instead.

See: help tellchat, help replay, help channels
