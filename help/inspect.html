In-Game Help Text

INSPECT
Author: Command Master
Keywords: inspect value worth examine identify
Type: Command

Syntax: inspect <item>|<slot> [room|inv|eq] - inspects an item.
Syntax: inspect <item>|<slot> [contianer] [room|inv|eq] - inspects an item inside a container.
Using 'room', 'inv', or 'eq' will ensure an item will only be from that location (the room or your inventory or eq). Optional.


The inspect command displays detailed information about a specific item, such as weight,
key words, wear locations and so on.

In order to view magical properties on an item, an Erius' Magnificent Magnifying Glass must
be in your possession. Mages can also use Detect Magic on an item to view magical
properties.

This item can be purchased from Ally's Shop, The Adventurer's Nook, in the Spur Merchant
District.

See: help magnifying glass, help detect magic, help appraise, help haggle, help bargain,
help currency
