In-Game Help Text

REPLAY
Author: Command Master
Keywords: replay
Type: Command

Syntax: replay - displays the most recent chat messages.
Syntax: replay CHAT - displays the most recent chat messages.
Syntax: replay NEWBIE - displays the most recent newbie messages.
Syntax: replay DRAGON_LINK - displays the most recent dragon_link messages.
Syntax: replay DEATHBOND - displays the most recent deathbond messages.
Syntax: replay WORSHIP - displays the most recent worship messages.
Syntax: replay WHISPER - displays the most recent whisper messages.
Syntax: replay TELLS - displays the most recent tells messages.
Syntax: replay EMOTE - displays the most recent emote messages.
Syntax: replay SAY - displays the most recent say messages.
Syntax: replay GROUP - displays the most recent group messages.


The replay command allows you to view recent or missed messages.


Some of the messages that can be replayed are: chat, tells, newbie, and says.
