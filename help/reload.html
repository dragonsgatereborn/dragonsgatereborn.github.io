In-Game Help Text

RELOAD
Author: Command Master
Keywords: reload
Type: Command

Syntax: reload <item>|<slot> - reloads the currently equipped firearm/crossbow with the indicated magazine.
Syntax: reload <weapon> <item>|<slot> - reloads the firearm/crossbow with the indicated ammo. Equipment and then inventory is checked for the weapon.
   If quiver is specificed for crossbows, it'll remove a bolt from the quiver.
Syntax: reload - reloads the firearm/crossbow automatically (crossbow: equipped quiver, firearm: first non-empty magazine found in the inventory)


The reload command is used to reload crossbows or firearms. Bolts are used from a quiver to
reload a crossbow, while a bullet or magazine are used for fire arms, depending on the
type. These weapons can also be unloaded, if needed.

See: help fire, help unload, help ranger
