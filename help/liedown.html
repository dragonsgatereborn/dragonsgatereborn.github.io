LIEDOWN
Author: Command Master
Keywords: liedown rest
Type: Command

Syntax: lie
Syntax: lie <item> - tries to lie on an item


The lie command puts your character into a prone position.

It is possible to lie on an item in the room, such as a chair, table or rune.

While prone, enhanced regeneration will occur.

See: help stand, help sit, help sleep, help wake, help rest
