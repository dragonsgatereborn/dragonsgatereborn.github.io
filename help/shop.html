In-Game Help Text

SHOP
Author: Command Master
Keywords: shop
Type: Command

Syntax: shop list|l [mob name] - displays the shop contents. mob name is optional (only if there are more than one shop in the same room)
Syntax: shop buy [mob name] <slot> - buys an item from the shop. mob name is optional (only if there are more than one shop in the same room (works on all shops in the room at once)
Syntax: shop buy [mob name] <slot> <amount>
Syntax: shop appraise <slot>
Syntax: shop inspect|examine|exam <slot>
Syntax: shop compare <shop slot> <your item>|<shop slot> - compares an item in the shop to an item in your inventory or equipment (Checks inventory first) or shop slot item
Syntax: shop sell <item>|<slot>
Syntax: shop sellstack <item>|<slot>

Rune Vendor Commands:
Syntax: shop list runes - displays your current rune weaves and renewal cost.
Syntax: shop renew all - renews all available runes to their maximum weaves.
Syntax: shop renew <name> - renews a specific rune type.

Note: You may use 'buy', 'sell' and 'list' as commands to buy, sell or list. They are aliases for the shop commands above.


The shop command allows you to interact with shopkeeprs to list wares, buy and sell items,
and inspect items.

To view the items a shop sells, type: list

To buy an item, type: buy <##

To sell an item, type: sell <item name>|<slot>|<sid> To sell an item stack, type: sellstack
<item name>|<slot>|<sid> To sell all items, type: shop sellall

shop detectmagic will work even if you are not a magic user.


If an item is marked KEEP or RETAIN, it will not be sold.
If a container is marked only RETAIN, the contents inside will be sold but not the container itself (KEPT items are skipped).


Shop search supports a special search syntax - please see the associated help file for more
information.

See: help buy, help sell, help list, help keep, help retain, help shopsearch
