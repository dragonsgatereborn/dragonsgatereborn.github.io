SHOPSEARCH
Author: Command Master
Type: Search
Keywords: ShopSearch

The shop search feature in the shop command can be used to search shop items while shopping
at shops for items.

The syntax is as follows:
Operator Searches:
shop search +<field to search> <operator> <data>

Non-Operator Searches:
shop search +<field to search> <data>


Fields:
affect_<mod type name>
name
type
wear_type
flag
cost
cost_silver

Operators:
=,==,<=,>=,!=

Examples:
shop search +affect_stat_hp > 50


shop search +name hood
shop search +type Armor

More than one + search can be used at once. If so, all elements must be true to return a
found item:
shop search +affect_stat_dex > 5 +wear_type FINGER
This would reteurn all items that had dex greater than 5 and could be worn on the finger
slot. Note: The syntax is not case sensitive.
