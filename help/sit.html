SIT
Author: Command Master
Keywords: sit
Type: Command

Syntax: sit - sit on the ground
Syntax: sit <item> - tries to sit on an item in the room


The sit command puts your character into a sitting position.

It is possible to sit on an item in the room, such as a chair, table or rune.

See: help stand, help liedown, help sleep, help wake, help rest
