In-Game Help Text

WHISPER
Author: Command Master
Keywords: whisper
Type: Command

Syntax: whisper <player> <message> - sends an in character private message to the player in the room


The whisper command sends a private IC message to another player.

Language does not work in whispers, all communication is automatically in common.

See: help language, help say, help shout, help groupchat, help channels
