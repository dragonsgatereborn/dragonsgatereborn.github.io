DESCRIPTION
Author: Command Master
Keywords: description
Type: Command

Syntax: description - enters the editor to write a description about your character..


The description command enters editing mode to write the description(physical and
background) for what players see when they look at you. The description text displays
immediately when a player looks at you - at the very top. The numbered lines in the
description editor do not display when a player looks at you to see your description.


There is no auto line-wrap but you can line-wrap your description at the end by typing @f.
This will format your description with proper line-wrawpping. To leave editing mode, type:
@f and then @q

Follow these steps to write a description using the editor:
1. Type desc
2. Type your text.
3. Type @f (to format text)
4. Type @q (to quit)
5. Type look <name>
If you wish to make changes, continue to step 6:
6. Type desc
7. Type @c (to clear all the text)
8. Go to Step 2.

A description is required by level 10.

This is a role play command - use it to enhance your character!

See: help role play
