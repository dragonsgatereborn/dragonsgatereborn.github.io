In-Game Help Text

RACES
Type: Race
Keywords: Races

A Tempest Season has many races for the player to select from.

Each has their own advantages and disadvantages. While races may start with different
attributes, they end up at the same maximum amount with the exception of dragons who gain
higher caps as they age.

Please see each race's help file for more information.

To learn much more about the races please visit this web page:
https://tempestseason.com/manual/races/

The following races are currently available for rollup:

 -  Anthian
 -  Arachnian
 -  Draco
 -  Drag-al

 -  Flerian
