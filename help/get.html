In-Game Help Text

GET
Author: Command Master
Keywords: get take grab retrieve
Type: Command

Syntax: get <item> - gets an item stack from the room
Syntax: get <item> - gets the #th item stack from the room that matches the item
Syntax: get <#> <item> - gets number of items from the item stack in the room

Syntax: get <slot> - gets an item stack by slot from the room
Syntax: get <#> <slot> - gets number of items from an item stack by slot from the room

Syntax: get all [item] - gets all, or all items with same name as input, of the items from the room

Container Get Syntax is similiar to the above:
Syntax: get [#] <item|slot> <container> [room|inv|eq] - gets an item from the corpse or container
Syntax: get all from <container> [room|inv|eq] - gets all, or all items with same name as input, of the items from the corpse or container
Syntax: get all [item] <container> [room|inv|eq] - gets all, or all items with same name as input, of the items from the corpse or container
Using 'room', 'inv', or 'eq' will ensure an item will only be from that location (the room or your inventory or eq). Optional.


The get command allows a player to pick up an object off the ground or from another object
such as a box or corpse.

To put all of the items on the ground from a corpse, use the 'strip' command. Get does not
work on player corpses, to loot a player corpse, use the 'strip' command.
