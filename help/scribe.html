SCRIBE
Author: Command Master
Keywords: scribe scroll read
Type: Command

Syntax: scribe <item>|<slot> - scribes the scroll to your memory, if you are a mage.


The scribe command is only used by Mages and allows them to commit a spell scroll to their
arsenal (spell screen).

Scrolls are purchased in the Spur Merchant District along with a small chance to find some
basic spell scrolls on low leveled monsters.

(You are looking to reduce scroll/text in the game, please see the help file for CONFIG)

See: help spells, help class ats.commands.combat.CastCommand, help config, help mage
