In-Game Help Text

CLASSES
Type: Class
Keywords: Classes

A Tempest Season has many classes for the player to select from.

Each has their own advantages and disadvantages.

Please see each class's help file for more information.

To learn much more about the classes please visit this web page:
http://tempestseason.com/manual/classes/class-overview/

The following classes are currently available for rollup:

 -  Barbarian
 -  Bard
 -  Cleric: Order of the Hand
 -  Cleric: Order of the Heart
 -  Cleric: Order of the Sword
 -  Fighter
 -  Forester
 -  Psion
 -  Rune Mage
 -  Thief

See: help <class name>
