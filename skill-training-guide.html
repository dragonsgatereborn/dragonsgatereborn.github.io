Learn an ability, follow its syntax, then train it

The live system separates learning a new ability from raising one you already know. Learning and training commands only work where an appropriate trainer is present.

View your current skills

CommandWhat it shows
SKILLSEvery skill currently available to your character, its remaining uses, and its level.
SKILLS <search>Filters that list. For example, SKILLS PSI shows matching skills.
INFOYour character, resources, position, and readied equipment.
HEALTHCurrent health, fatigue, PSI when applicable, and visible injuries.

The Remain number tracks progress toward the skill's next training point. An eligible use may reduce it, depending on the ability and location. The Training Grounds' practice-target rooms explicitly state that fighting there does not produce learning.

Learn a new ability

  1. Stand in a room with an appropriate trainer.
  2. Type LEARN LIST to see abilities and specializations available there.
  3. Use LEARN ABILITY <slot> to learn a listed ability.
  4. At the appropriate level, use LEARN SPEC <slot> for a listed specialization.
  5. Run SKILLS afterward to confirm the new skill appears.

LEARN LIST also shows the current cost. Availability depends on the trainer, class, race, level, and current implementation.

Use the command shown for that ability

There is no single command that activates every ability. Type HELP <ability name> and follow the syntax shown there.

Ability typeTypical live syntax
Active skillSome use USE <skill> <target> or accept the skill name directly.
SpellUse INVOKE <spell or alias> [AT] <target>.
Psionic abilityUse PSI <ability> [AT] <target>.
Passive or automatic abilityIt triggers through normal play and cannot be activated with USE.
Command-driven abilityUse its related command, such as ID ARMOR, rather than assuming USE.

Practice targets accept KILL TARGET for basic combat testing. They are useful for checking commands and reactions, but their rooms explicitly disable combat learning.

Train an ability that is ready

  1. Return to an appropriate trainer and type TRAIN LIST.
  2. Read the live entry for the ability. It may require its Remain value to reach zero before training is available.
  3. Use TRAIN <slot> for a listed ability or TRAIN SPEC <slot> for a listed specialization.
  4. Run SKILLS afterward to confirm the result.

The trainer's live list is the authority for requirements. It can show tier points, money, or an item when applicable. TRAIN TIER COST is active and checks the current price of an optional additional tier point without purchasing it. Tier-point purchases and respecs are advanced choices, so this beginner guide does not direct players to use them.

Common problems

  • “There is no trainer here”: the syntax is valid, but that room cannot teach or train you.
  • No ability is listed: it may belong to another class, race, level, trainer, or a system not currently available.
  • Remain does not change: the room, target, action, or ability may not allow learning—or the action may not have completed.
  • USE reports a passive skill or the wrong ability: stop and check HELP <ability name>; use the ability's own syntax.
  • Old website mentioned LEARN <slot>: use the current LEARN ABILITY <slot> syntax.

Trainer placement and costs can change during beta. Some live trainer and help output still contains unavailable or legacy directions. Commands on this page were checked against live behavior; when the game contradicts itself, ask the community before spending money or changing training.
