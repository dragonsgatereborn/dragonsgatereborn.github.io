Skills are learned, used, then trained

The live system separates learning a new ability from raising one you already know. Learning and training commands only work where an appropriate trainer is present.

View your current skills

CommandWhat it shows
SKILLSEvery skill currently available to your character, its remaining uses, and its level.
SKILLS <search>Filters that list. For example, SKILLS PSI shows matching skills.
INFOYour character, resources, position, and readied equipment.
HEALTHCurrent health, fatigue, PSI when applicable, and visible injuries.

The Remain number tracks uses still needed for that skill's current progression. Using an eligible skill can reduce it. A successful effect is not always required, but some rooms or targets may explicitly disable learning.

Learn a new ability

  1. Stand in a room with an appropriate trainer.
  2. Type LEARN LIST to see abilities and specializations available there.
  3. Use LEARN ABILITY <slot> to learn a listed ability.
  4. At the appropriate level, use LEARN SPEC <slot> for a listed specialization.
  5. Run SKILLS afterward to confirm the new skill appears.

LEARN by itself displays syntax, but it does not list the trainer's offerings. Availability depends on the trainer, class, race, level, and current implementation. The game may also support learning from eligible knowledge items with LEARN ITEM <item or slot>.

Use and advance a skill

  1. Use USE <skill> <target>. If the target is omitted, the game attempts to target you.
  2. Many skills can also be entered by name because the game checks skill names when no regular command matches.
  3. When the skill is ready and you are at an appropriate trainer, type TRAIN LIST.
  4. Use TRAIN <slot> for an ability or TRAIN SPEC <slot> for a specialization.

Training can require a tier point, money, or an item. The trainer tells you what is needed. TRAIN TIER COST checks the next purchasable tier point; TRAIN TIER BUY buys it. Do not use the respec command casually—it resets trained non-natural abilities and charges a fee.

Common problems

  • “There is no trainer here”: the syntax is valid, but that room cannot teach or train you.
  • No ability is listed: it may belong to another class, race, level, trainer, or a system not currently available.
  • Remain does not change: the room, target, action, or ability may not allow learning—or the action may not have completed.
  • Old website mentioned LEARN <slot>: use the current LEARN ABILITY <slot> syntax.

Trainer placement and costs can change during beta. Use HELP LEARN and HELP TRAIN for the current syntax, then ask the community if you need help finding the correct trainer.
