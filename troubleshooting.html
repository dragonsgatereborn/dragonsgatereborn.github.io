Fastest Reliable Connection

game.dragonsgatereborn.com · Port 8555

Use a standard, non-SSL connection. The hostname is preferred over the direct IP address.

If you cannot connect

  1. Confirm the host is exactly game.dragonsgatereborn.com and the port is 8555.
  2. Turn SSL/TLS off for port 8555.
  3. If your saved profile still fails, create a fresh connection profile so an old SSL setting or proxy is not reused.
  4. Try another network or client to distinguish a local block from a game outage.
  5. Check Discord for maintenance or copyover notices before asking staff to investigate.

Secure port 9555

Port 9555 accepts SSL/TLS connections, but the server is currently presenting an expired certificate issued for Tempest Season rather than the Dragon's Gate Reborn hostname. Some clients warn or refuse the connection. Until that certificate is renewed, use port 8555.

Login and account problems

  • No account yet: choose 2. Create new account on the game login screen.
  • Name rejected: account names are single words and must be different from character names.
  • Password trouble: do not post credentials. Ask in Discord for the appropriate private support path.
  • Character creation confusion: use help <race> and detail on the race screen, or follow the website walkthrough.

Accessibility and comfort

Text and color

Increase the client font size and line spacing. Choose a high-contrast ANSI palette; if colors make information harder to read, disable or simplify ANSI color in the client.

Screen readers

Use a client with accessible output review and keep the input field separate from the output window. Reduce mapper, sound, and trigger announcements that interrupt room text.

Mobile and tablet

Use a client that supports saved profiles and customizable command buttons. Keep movement and common information commands available without relying on precise taps.

Website motion

The website honors your device's “Reduce Motion” setting and removes its page-entry animation when that preference is enabled.
