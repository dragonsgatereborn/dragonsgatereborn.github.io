DIE
Author: Command Master
Keywords: die revive death dying debt resurrect


Type: Command


The die command brings you back to life!

If you have been killed in combat, you may die and return to life. You will be revived at
your religion's temple, or the center of Spur if there is no temple.

Note: If Quest Mode is on, your revive location is the current room.


There are penalties associated with dying if you are over level 10: a debt to your
experience will incur. This debt must be paid back before any progress will resume for the
next level. The current debt can be seen under the score command.

You keep all of your equipment, items, and currency when you die.

(Exploring the game while under level 10 is a good idea since there are no penalties when
dying.)

See: help class ats.commands.informative.ScoreCommand, help experience, help quest mode

DEPOSITPROTOTYPE
Author: Command Master
Keywords: depositprototype 
Type: Command

DEPOSIT

Deposit materials and gold into the material bin (Barrin's Bountiful Bin)


Syntax: deposit store [item name|slot] - Deposit an item in the material bin. You won't be able to retrieve it after.
Syntax: deposit storestack [item name|slot] - Deposit an entire stack of items into the material bin.
Syntax: deposit gold [amount] - Deposit gold into the material bin.
Syntax: deposit silver [amount] - Deposit silver into the material bin (converted to gold, 100 silver = 1 gold).
Syntax: deposit view [players|item nid|player name] - View the bin; 'players' shows each player's contribution %, or (staff/helper) pass an item nid or a player name.


The deposit command allows you to deposit materials and gold into the material bin
(Barrin's Bountiful Bin) for the city. Spur tracks everything that is deposited - both
current and all time. The more materials added to the bin the more the city can build
structures with. Some materials can be enchanted - see the help topic below.

Please be aware that any items deposited will be removed from your inventory and there is
NO guarantee if you will receive reimbursement from this. City officials will remove the
materials for use in the city and they may directly or indirectly reward the players.

See: help inventory, help inspect, help infuse material

DELAY
Author: Command Master
Keywords: delay delays stun
Type: Command

Syntax: delay - displays current delay and combat timer.

The delay command shows the current delay and combat timer of a player.

Delays occur when an action takes place, such as swinging a weapon, casting a spell, and,
picking up, unlocking or selling hordes of items.

The combat timer begins whenever a hostile action is performed. Certain commands and
actions are restricted while in a combat timer, such as the quit command.

The delays tick down every second and any commands entered which also are delayed, will be
placed in the queue. Not all commands are delayed actions, and can be performed while in
delay. Commands like say, inventory, and skills are examples for non-delayed commands.

See: help class ats.commands.informative.CoolDownsCommand,

GUARD
Author: Command Master
Keywords: guard defend
Type: Command


Syntax: guard <target>


The guard command allows you to attempt to draw a monster's attacks away from someone, and
onto yourself. The attempt always works, as long as you are close enough to step in front
of them.

Note: Monsters choose who they wish to target each attack and may revert back to the
defended target if they attacked the monster again or if the monster is aggressive,

There are abilities which lock a monsters target to you and are more effective than guard.

DESCRIPTION
Author: Command Master
Keywords: description 
Type: Command

Syntax: description - enters the editor to write a description about your character..


The description command enters editing mode to write the description(physical and
background) for what players see when they look at you. The description text displays
immediately when a player looks at you - at the very top. The numbered lines in the
description editor do not display when a player looks at you to see your description.


There is no auto line-wrap but you can line-wrap your description at the end by typing @f.
This will format your description with proper line-wrawpping. To leave editing mode, type:
@f and then @q

Follow these steps to write a description using the editor:
1. Type desc
2. Type your text.
3. Type @f (to format text)
4. Type @q (to quit)
5. Type look <name>
If you wish to make changes, continue to step 6:
6. Type desc
7. Type @c (to clear all the text)
8. Go to Step 2.

A description is required by level 10.

This is a role play command - use it to enhance your character!

See: help role play

DRAG-AL
Type: Race
Keywords: Drag-al
Genders: Male, Female, Non-Binary
Allowed Classes: Fighter, Cleric: Order of the Heart, Cleric: Order of the Sword, Cleric:
Order of the Hand, Bard, Thief, Barbarian, Forester, Rune Mage
Racial Tensions: Monitanian
Racial Abilities: None

Drag-als are short, dragon-like beings who possess the power to breathe fire but lack the
claws and wings of true dragons. These jovial creatures enjoy jokes, ale, and storytelling,
naturally gravitating toward trading and performance work rather than laborious toil. Their
natural scale armor provides innate protection, and they possess night vision along with a
knowledge of additional languages. Drag-als form friendships readily and are known for
their superior bargaining skills, though their small stature creates challenges in direct
combat. Monitanians regard them negatively, viewing them as loud and obnoxious. Common
professions include Bard and Runemage, with some pursuing paths as Thieves, Fighters, or
Clerics. Barbarians and Foresters among them are rare.

To learn more about the Drag-al please visit the web page:
http://dragonsgatereborn.com/races/race-dragal.html


See: help <ability name>, help <class name>, help races

DRACO
Type: Race
Keywords: Draco
Genders: Male, Female
Difficulty: EASY
Role: Damage, Tank
Allowed Classes: N/A - DOES NOT SELECT A CLASS
Racial Tensions: They form their own opinions of each race as they play


Dragons are the most powerful of all the races of Dragon's Gate Reborn. They represent the
apex of power within the game's racial hierarchy, growing through distinct life stages from
young Draco to the ancient and mighty Imperial dragon.

Unlike other races, dragons operate outside standard game structures - they lack a
designated class system and do not worship the mortal pantheon of gods.
