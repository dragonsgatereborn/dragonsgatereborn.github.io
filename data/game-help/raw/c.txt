INVENTORY
Author: Command Master
Keywords: inventory carry items
Type: Command

Syntax: inventory - displays your inventory.
Syntax: inventory sort inv|bank|room|<container name> <sort type>|list - changes the sorting method of the selected inventory.
  Use 'list' to see a list of available options.
Syntax: inventory carry - displays your carry information regarding your inventory.
Syntax: inventory updateKeys|updateGems|updateCoins - looks through all of your inventory items (not in containers) and updates all non-keys/etc to be keys, which are keys and are also non-keys during the key updating process.


The inventory command shows all currently held items.

When you receive an item, such as picking one up, it goes into your inventory. You can only
carry a limited amount of items (35 item stacks). Buying containers (such as backpacks) and
using the bank vault can store more items.

You may drop, give, inspect, keep, retain items (and more!).

See: help drop, help give, help inspect, help keep, help retain, help equipment, help box,
help vault, help cache, help break,

CACHE
Author: Command Master
Keywords: cache 
Type: Command

Syntax: cache store <item>|<slot> - stores the item stack in the cache
Syntax: cache store <#> <item>|<slot> - stores a number of items from your inventory
Syntax: cache remove <item>|<slot> - retrieves the item stack from your cache (staff and helper only)
Syntax: cache view


The cache command allows you to manage your stored items in the cache: ONLY storing items.
Items CANNOT be removed unless a specific condition occurs. Specific conditions usually are
RP based, for example, a bank robbery occurs and now you can remove items from the cache.
These conditions are usually explained to you when you are given a cache.

The cache has a has 150 spaces for items and items inside containers are counted towards
the total.

Upgrades may be not currently be purchased. Gaining a cache is a RP reward and you will be
approached to acquire one; please do not ask for a cache.

See: help box, help vault, help inventory, help roleplay

PAY
Author: Command Master
Keywords: pay bounty wanted law pay jail criminal
Type: Command


Syntax: pay bounty - tries to pay your bounty to remove the WANTED flag. You must be at a bounty office.
Syntax: pay check - views the cost to remove your bounty. You must be at a bounty office.


The pay command pays off a bounty (WANTED flag) gained from attacking the guards, pick
pocketing or similar illegal activities.

You can only pay a bounty at the bounty office, Northwest from the center of Spur.

The cost of the bounty scales based on character level.

Being Wanted will cause the city guards to attack on sight so be careful while moving int

CALL
Author: Command Master
Keywords: call pets animal tag mounts
Type: Command

Syntax: call <item> - summons the pet on a pet tag or mount on a mount tag!
Syntax: call <slot> - summons the pet on a pet tag or mount on a mount tag!
Syntax: call patreonPet - summons the patreon pet, if one is made. Use the Patreon command to create a pet!
Syntax: call patreonMount - summons and mounts the patreon mount, if one is made. Use the Patreon command to create a mount! (Tier 5)

Syntax: call dismiss [longID]|all - dismisses your current pet. If the tag was a single use, this pet will be lost forever.
Syntax: call list - List the pets and their LongID so you can dismiss or interact with them via order.
Syntax: call pets - calls for your already existing pets and has them returns to you! This won't work if the pets are in combat.
Syntax: call resonance - summons your already existing resonance to you!


The call command summons a mount, a new pet, dismisses a pet, or returns a lost pet to your
side.

Typically, pets and mounts must be purchased or acquired through a role play event. They
can then be summoned with the call command and controlled with the order command.

Pets can perish and be lost forever. Be careful of giving them rare and expensive items as
they can be easily lost as pet inventory is not saved. Mounts do not perish and last
forever.

See: help order, help class ats.commands.items.PatreonCommand, help dismount, help role
play

TRAIN
Author: Command Master
Keywords: train trainer guildlist classlist raise
Type: Command

Syntax: train list - lists the abilities and specializations that can be trained at this location.
Syntax: train <slot> - trains the ability up to the next level. This will require a tier point and sometimes an item (the train will inform you on what is needed).
Syntax: train spec <slot> - trains the specialization up to the next level. This may require a tier point and a small fee.

Syntax: train tier cost - checks the cost of the next tier point you may buy.
Syntax: train tier buy - buys a tier point for the associated gold price.
Syntax: train tier respec confirm - resets all of your tier points for 5,000 gold. All of the abilities and specializations you trained will be set to lv 1. You will receive a 75% refund of your ability points.

Syntax: train guildlist - views your standing in your classes guild.
Syntax: train history - views your training attribute gain history.


The train command raises a level of an ability, specialization, or aptitude to the next
level.

The cost of raising to the next level varies:
1. Possibly using a TIER POINT and/or money, if applicable to raise an ability in level.
2. Using a TIER point (and money, if applicable) to raise a specialization in level.


The money cost to raise an ability up a level depends on the amount of uses the ability has
left.

You gain tier points upon leveling up.

You can also buy tier points at the trainer using 'train tier buy'.

Respeccing your tier points will set all of your non-natural abilities to their initial
level.

To learn more about training and learning new abilities visit the manual:
www.tempestseason.com/manual/abilities/#Training_Abilities_and_Specializations

See: help learn, help class ats.commands.PracticeCommand, help class
ats.commands.informative.SpecializationsCommand, help tier points, help anima convergence

CONFIG
Author: Command Master
Keywords: config set
Type: Command

Syntax: config <config type> - toggles the config option on/off.
Example: config NO_COLOR - toggles the coloring of text on/off.

Syntax: config screenreader - sets your configuration setup to work better for screeneaders.
Syntax: config buffersize <lines> - sets the number of lines per Hit Enter text.
Syntax: config export [delimiter] - exports configs for use in another character (copy and paste). If 'delimiter' is used, output is on a single line.

Syntax: config list - views the current configuation setup.
Syntax: config types - views each config and their description.

Syntax: config messages <messageType> <mode> - sets mode (FULL, BRIEF, NONE) for a given message type(YOURS, OTHER).
Syntax: config messages list - views current modes for all messages.
Syntax: config batchedcombat - toggles batched combat message mode on/off.

To change colors, see color help


The config command allow you to control certain features and behavior in the game. For
example, this command can be used to turn the map on/off, chat color, and hints.

To configure color, see help color

Configs can be exported with config export for use on other characters.

See: help inspect, help inventory, help brief, help color, help channels

COLOR
Author: Command Master
Keywords: color colorset ansi colors colours
Type: Command

Syntax: color set <type> <colorTag>|default - sets the given type to use the indicated color tag.
Syntax: color list - lists all current colors.

Syntax: color brief - toggles brief color on/off.
Syntax: color none - toggles no color on/off.
Syntax: color xterm - toggles xterm color(256 colors - need client support) on/off.


Syntax: color trueColor - toggles true color on/off and xterm on if off.


The color command can change many aspects of color in A Tempest Season.

The following color codes exist:
#c/#C: cyan/bright cyan
#r/#R: red/bright red
#g/#G: green/bright green
#b/#B: blue/bright blue
#p/#P: purple/bright purple
#y/#Y: yellow/bright yellow
#s/#S: gray/black
#w/#W: gray/white
#d: default color
#h: default highlight color
#x: terminates color and reverts to client's default

The game also supports xterm color (type: color xterm to turn on):
#e1 to #e255: a specific color, that matches the chart from the following website:
https://i.stack.imgur.com/KTSQa.png

The game also supports true color (type: color trueColor to turn on):
#t(6-digit hex code): a specific color that matches the hex code in rgb color space. Example: #t(e3cdb6)
#t[keyword]: a specific color that matches the keyword. Example: #t[cotton]
 Note: Keywords are added by Actinate and Dayrinni. Not all keywords will exist.

See: help put, help get, help look,
