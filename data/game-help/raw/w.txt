WEAR
Author: Command Master
Keywords: wear 
Type: Command

Syntax: wear <item>|<slot> [wear slot] - wears an item on the default slot or the provided one. Slot is optional.
Syntax: wear <inventoryIndex> [wear slot] - wears an item at the inventory slot on the default slot or the provided one. Slot is optional. (Check inventory for index)
Note: If using the wear slot option, it must be fully typed out. For example wear ring right finger (NOT right fing)


The wear command allows you to wear or equip an item. If an item is already equipped, it'll
be replaced.

You may also specify what wear location to wear an item at if the item has mulitple slots.
For example, wearing a headdress as a HAT rather than a HEAD (armor).

See: help wield, help dualwield, help remove, help equipment, help inventory,

WIELD
Author: Command Master
Keywords: wield 
Type: Command

SSyntax: wield <item>|<slot> - wields the item in the primary slot.

See help: dualwield


The wield command tries to equip a weapon in the primary or secondary slot.

A weapon is needed to perform any melee attacks and to parry. Some skills may also require
an equipped weapon.

Some weapons can be swapped between 1 hand and 2 hand. To do this, use the grip command.
Gripped one handed weapons receive a damage bonus compared to one handed weapons but less
than fully fledged 2 handed weapons.


Not all classes can dual wield.

To dual wield a weapon, see help dualwield

See: help dualwield, help grip, help class ats.commands.informative.AttackInfoCommand, help
wear, help hold, help remove, help equipment, help inventory, help inspect,

INSPECT
Author: Command Master
Keywords: inspect value worth examine identify
Type: Command

Syntax: inspect <item>|<slot> [room|inv|eq] - inspects an item.
Syntax: inspect <item>|<slot> [contianer] [room|inv|eq] - inspects an item inside a container.
Using 'room', 'inv', or 'eq' will ensure an item will only be from that location (the room or your inventory or eq). Optional.


The inspect command displays detailed information about a specific item, such as weight,
key words, wear locations and so on.

In order to view magical properties on an item, an Erius' Magnificent Magnifying Glass must
be in your possession. Mages can also use Detect Magic on an item to view magical
properties.

This item can be purchased from Ally's Shop, The Adventurer's Nook, in the Spur Merchant
District.

See: help magnifying glass, help detect magic, help appraise, help haggle, help bargain,
help currency

PAY
Author: Command Master
Keywords: pay bounty wanted law pay jail criminal
Type: Command

Syntax: pay bounty - tries to pay your bounty to remove the WANTED flag. You must be at a bounty office.
Syntax: pay check - views the cost to remove your bounty. You must be at a bounty office.


The pay command pays off a bounty (WANTED flag) gained from attacking the guards, pick
pocketing or similar illegal activities.

You can only pay a bounty at the bounty office, Northwest from the center of Spur.

The cost of the bounty scales based on character level.

Being Wanted will cause the city guards to attack on sight so be careful while moving int
the city!

WMOTE
Author: Command Master
Keywords: wmote arrival
Type: Command

Syntax: wmote enter <string> - switches to a new enter emote.
Syntax: wmote exit <string> - switches to a new exit emote.
Syntax: wmote current - views the current wmotes.
Syntax: wmote clear - resets your current wmotes to be default (nothing).


Wmote allows a player to change their enter and exit messages while moving between rooms
from the default enter and exit messsages.

Instead of seeing the default messages:
Dayrinni leaves southeast.
Dayrinni enters from the north.

Custom messages can be displayed, such as:
Dayrinni leaves southeast, while skipping.
Dayrinni enters, talking to everyone he sees from the west.

This is a role play command - use it to enhance your character!

This command will be monitored for abuse. Report anything inappropriate, including OOC
messages or anything that violates the game policy.

See: help emote, help smote, help socials, help pose, help mood, help role play
