Summary: Identify Magick is an aura-detection check that confirms whether an item carries active magick.

Notes:
Success returns the magick-aura detection line; failure returns uncertain/no-clue feedback.

Resolution scales with skill plus INT/WIS/PER versus enchant complexity.

Delay target is 20-30s with progression on valid identify attempts.

Player Overview

Description: Allows you to see if an Item has a magickal matrix

Who Can Learn It: Everyone

What It is Supposed to Do: See if an item is magickal

What it Does: Guesses if the item is magickal

Activation: Identify Magick On (target item)

Usefulness (Low Levels): Often fails or gives a wrong guess

Usefulness (Mid Levels): Often gives a correct guess

Usefulness (High Levels): Always gives a correct guess

How to Practice: Grab an item and try to find if it's magickal

Tips: Often a useful skill to practice while talking or waiting for something

Unconfirmed Rumors (May or May Not Be True): None

Notes:
(May or May Not Be True): Puts you in delay for 30 seconds
