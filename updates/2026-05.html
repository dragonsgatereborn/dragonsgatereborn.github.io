PSI System Improvements

Good day!

Here is the update to the update. Enjoy reading the update notes for this update.

  • Many improvements to the PSI system!
  • PSI regeneration calculation improvements.
  • PSI point display improvements.
  • PSI Damage bypasses body and worn armor.
  • ESP should now grant contact target to a target.
  • Resist interaction with PSI cost and delays: no PSI cost, no long delay, no message display when a cast affects nobody.
  • Better centering handling - no glow if under centering and trying to center.
  • PSI Detect Invisibility shouldn't display hidden characters now.
  • Improved Contact error messaging.
  • New feature to mark abilities as simply not able to gain uses (Centering will never gain a use now).
  • PSI Centering message improvements.
  • PSI % on prompt should not appear.

Please test the above to ensure they are working correctly!

Thank you!

DGR Team

Initial Berserk and Psionics Rollout

Good day!

Here is the update to the update. Enjoy reading the update notes for this update.

  • Improvements to copyover. Report any issues during and after a copyover.
  • Currency and items should respect the coloring of the room description better.
  • The initial iteration of the Barbarian Berserk skill is in. Test it out, give feedback, and remember those memories!
  • Arachnians should no longer be able to use the InvokeCommand.
  • Light sources currently in use, such as torches, should now show up in the INFO command.
  • Implemented the initial version of the Psionics system. This includes INFO PSI, seeing PSI points in INFO and Health, psionic usage such as psi dart ork, messaging, psionic resists, and so on.
  • The first 5 levels of psionics are here. Since the psionics are slightly more complex than Runemage spells at this time, I needed to search the logs for functionality. During this, I decided to bring over the messaging as best I could based on what I found, so this should be closer to the original DGate feel. The logs did not have every single bit of functionality, so feel free to share more information.
  • The old PSI Dart has been remade. This new psionic uses a new ID, and the old one no longer applies. You may see some remnants of the old one. If you do, let me know and I will adjust your character. Nothing is lost. I will also take a look. Your character should auto-update when you log into the game. If you are a Psion, please log on and give this new dart a try.
  • The new psionics have aliases, so you can use psi dart ork instead of psi psidart ork.
  • First iteration of PSI point generation. This is dynamically calculated, so we can adjust it as needed.
  • A cursory look at Use testing was done, but as usual, we need you to collect more detailed information to get Use generation correct. Please report!

What's Not In:

  • Not all racial aspects for psionics are in yet, such as everything for Psycians. Humans do have 80% psionic resist.
  • No latent psionics.
  • Anything not mentioned above that you know of. Feel free to share more information so we can capture it and get it added in!

Questions:

  • How was psionic damage handled? Did it bypass armor? Anything else?
  • What were the starting ranges for PSI points?
  • Were there any ways to regenerate PSI points besides Centering? For example, did they tick upward on each tick?

We shall iterate on Psionics just like we did for the Magick System. Get that feedback in, folks!

Thank you!

DGR Team
