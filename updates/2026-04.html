Shop, Spell, Networking, Room, and Equipment Update

Good day!

Here is the update to the update - enjoy reading the update notes for this update.

  • Themed the shop view to be more accurate.
  • Fixed issue with Focus Force not displaying the proper OR values after logging out.
  • Fixed some issues with flight and targeting messaging.
  • Beneficial spells should bypass the resist check unless you are a Hithual or Arachnian.
  • No longer can you mem corridors for spells you don't have access to yet.
  • When picking up coins, it'll tell you how much you pick up.
  • The item listing in rooms is now formatted along with the room description.
  • The played command has been themed. However, we still don't have an in-game calendar in. That will come in the future.
  • Updated REFLECT DAMAGE to capture the damage before armor reduction.
  • InvokeCommand now lets you target yourself with hostile spells. Each time you blast yourself the DGR team gets more powerful!
  • The targeting has changed to allow for <blank> to target yourself automatically on non-harmful spells, and it doesn't rely on the last known targeting feature any longer. This should represent DG more closely.
  • Made some enhancements to the networking and copyover systems to reduce memory usage overtime. This means there was some changes deep in the system (places where I don't like to go but will go there for you!) so report any Connection Funny Business to me and I'll take a look. I did testing with multiple characters and connections and it seemed to work without issue as well as deploying to ATS beforehand to do more in-depth testing.
  • Added LIT flag to allow for baseline illumination in rooms. DARK still overrides it though.
  • Holy Mist should now only be usable on the undead monsters - test it out and give feedback!
  • Added a prototype of needing to unready/remove equipment before equipping it. We will refine some more - the team will build a matrix of how this worked.

Thank you!

DGR Team

April 1, 2026 at 10:24 - Wizzydizzy [MUD]

Roadmap Progress: Code First, Areas Next

Hello!

We wanted to give an update regarding the past few months since open. Overall, we are making great progress. We’ve implemented several systems, some of them major, such as the first iteration of the magick system. Everything is going well! The codebase conversion is moving along, and with the recent update, we crossed the 800k lines of code mark. We are making consistent progress in theming the game as well. Dace and Act are compiling data and building out information so we can continue our progress in making DGR!

I wanted to briefly talk about the progress for code vs areas and where we are, since we’ve been at level 3 for a while. I think it’s best said with a picture!

What this graph is basically showing is that the code comes first. All of the initial effort in creating the game engine must be done in the code first. So that is why we are still at level 3, pushing out system after system while staying in TG. Once the majority of that work is completed, we shift to level 5 and beyond: going to Spur. This then means the main effort is area work: all of the items, NPCs, rooms, hunting grounds, shops, and so on. At this point, the amount of code work will be much lower. If you like analogies, it’s like blowing up a balloon until it bursts: you need to blow a lot (the code) before it explodes (going to Spur). So even though it may not feel like we’ve made significant progress, seeing the above, it is clear we have made great strides!

We’re always open to discussing this and any topic related to the roadmap and getting us there. As always, thank you for your testing and contributions - keep it up!

Thank you!

DGR Team

Currency, Focus Force, Quick Draw, and Shield Parry Update

Good day!

Here is the update to the update - enjoy reading the update notes for this update.

  • Improved the currency display in rooms and picking items up.
  • Themed the item list in the rooms: Items are now listed at the end of the room description.
  • Fumbling a quick draw shouldn't award a use any more.
  • Fixed an error with the Merc Tour applying the attributes incorrectly in 7.6% of circumstances. In addition, added logging to better track this. We are reviewing past discussions and applying fixes to characters by hand. If you received a raise during the tour, send Dace and I a DM. We will review and adjust your character.
  • Adjusted Focus Force to have the proper OR rates and also added a new weapon damage ModType, so that affect can be solely used on getting a use. So you'll only get a use if you deal damage to the target. Additionally, Focus Force should now print the familiar OR message on use.
  • Adjusted Quick Draw to the new equations based on community discussion.
  • Adjusted Shield Parry to the new equations based on community discussion. Shield Parry will be much easier to block with now.
  • Added a temporary debug printout to Shield Parry for all players to see so we can ensure the %'s look good.

Thank you!

DGR Team
