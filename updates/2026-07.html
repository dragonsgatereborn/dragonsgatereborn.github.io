Pickpocketing and NPC Coin Handling Added

Good day!

Here is the update to the update. Enjoy reading the update notes for this update.

  • ID Mag can now use "mag" and "magic".
  • Smile magic now should work with punctuation. eg: smile, looks at you.
  • The () around emote has been removed for now, until we get all of the socials into the game.
  • Added in thief skill picking pockets. This was based on primarily the data from logs provided to me. Please test and give some feed back here: pickpocket-discussion
  • NPCs now load their coin upon spawn and place it into their inventory instead of loading it upon death. When they die, their coin gets placed into their corpse just like previously. This change needed to be done due to pick pocket subtracting from the actual treasure NPCs had. As such, you may see slightly different behavior and report any issues.

Thank you!

ID Skills, Berserk, Group, and Map Update

Good day!

Here is the update to the update. Enjoy reading the update notes for this update.

  • ID Skills have temporary debug messaging to aid in testing.
  • ID Armor will now ID shields.
  • ID Skills allow use while hidden now.
  • ID Gem and Magick now can be used on items in the room.
  • When you leave berserk, you'll now lose 50-70% of your current FTG instead of 100%. This is easily adjustable as we test and discover new data, we can update accordingly.
  • To enter berserk, you need at least 10% FTG. This is easily adjustable as we test and discover new data, we can update accordingly.
  • Berserk stop now displays a calming attempt message.
  • Berserk stop now has a base 10% chance to stop plus +1% per berserk level. This is based on discussion here: bugs-and-defectsBerserk Stop
  • Fixed some issues in roll-up with mistyping 'y' would actually be a failure. eg 'y]' would be a decline. This should no longer be the case now.
  • Converted the Group command to use the Command DSL system. It should be functionally the same - if you run into trouble, use !group to use the old one.
  • Maps now have the ability to show other/nearby areas. This is essentially a case-by-case basis flag we can turn on so not all areas will do this.
  • Added some more enhancements to the Command DSL system.

The engine is now 960,830 LoC. Almost a million!

Thank you!

DGR Team

Identify Skills Released

Good day!

Here is the update to the update. Enjoy reading the update notes for this update.

  • The skill Identify Armor is in.
  • The skill Identify Weapon is in.
  • The skill Identify Gems is in.
  • The skill Identify Magick is in.
  • You should be able to learn these at the trainer for free.
  • Updated to the new scripting system - this should have little impact as the game only had 3 total scripts as opposed to +1000 for ATS.

A few quick notes:

  • Based on the logs, it seemed it was easy to get uses when using some of these skills. Feel free to share your feedback.
  • There doesn't seem to be any magick or gem items in the game currently, so using ID gems and magick likely is not possible at this time. I'll see if Dace and Act can add a few items to do some testing.
  • As usual, we look forward to getting your feedback as your memories are jogged while using them and we'll make updates. The DGate website had only high level information on these and the ID Gems page simply did not seem to exist (404 error).
  • Please put any discussion in id-skills-discussion and open a bug report in the bugs-and-defects for when you discover an issue.

Next uppdate involves looking at the Berserk feedback and starting Thieves.

Thank you!

DGR Team
